# Avocet AV Website

Static brand site for Avocet AV — wedding and small-event audio in Utah & Salt Lake counties. Built with [Astro](https://astro.build/), deployed to GitHub Pages at `avocet-av.com`.

## Local development

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output to ./dist
npm run preview  # serve the built site locally
```

## Updating content

Everyday edits live in `src/data/`:

- `site.ts` — business name, tagline, phone, email, service area
- `packages.ts` — package tiers, BASE/HOURLY rate, founding-client promotion
- `faqs.ts` — FAQ entries
- `booked.ts` — booked dates; **autogenerated from the calendar in CI** (see below)

Copy elsewhere (hero, services blurbs, contact page logistics) lives directly in the component files under `src/components/` and `src/pages/`.

## Availability / calendar sync

The availability checker reads from `src/data/booked.ts`, which is rewritten on every CI build by `scripts/sync-bookings.mjs` from a Google Calendar iCal feed. Only event *dates* (YYYY-MM-DD) are written out — titles, descriptions, and attendees never leave the script, so the repo stays safe to be public.

**Setup (one-time):**

1. In Google Calendar, create a dedicated calendar called e.g. "Avocet AV Bookings" — separate from anything personal.
2. Open the calendar's settings → **Integrate calendar** → copy the **Secret address in iCal format** (the URL ending in `/basic.ics`). Treat it like a password.
3. In the GitHub repo: **Settings → Secrets and variables → Actions → New repository secret**. Name it `BOOKINGS_ICAL_URL`, paste the URL.
4. Done. The next build will sync.

**Cadence:** Builds run on every push to `main`, on manual dispatch, and on a daily cron at 09:00 UTC so newly-added bookings propagate overnight without a code change.

**Local testing:** You can populate `src/data/booked.ts` by hand to test the date-checker. Your local edits survive `npm run dev` but are overwritten by the next CI build.

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds and publishes to GitHub Pages. The `public/CNAME` file pins the site to `avocet-av.com`.

One-time setup in the repo settings: **Settings → Pages → Source: GitHub Actions**.
